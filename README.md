# 🍽️ Flutter Recipe App

A Flutter-based mobile application designed to help users explore and discover different recipes. The app provides a user-friendly interface to browse delicious dishes with food images and recipe details.

## ✨ Features

- **Recipe Browsing:** Explore different recipes.
- **Food Images:** View images of delicious dishes.
- **Recipe Details:** Display information about recipes.
- **User-Friendly UI:** Simple and clean interface.
- **Offline / Online Support:** Project designed with offline and online usage in mind.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Flutter | Mobile app development |
| Dart | Programming language |
| SharedPreferences | Local key-value storage |
| Material Design | UI design |

## 🚀 Getting Started

Follow these steps to run the project.

### 1. Clone the Repository

```bash
git clone https://github.com/fathimanadin824-glitch/flutter-recipe-app.git
```

### 2. Open the Project

```bash
cd flutter-recipe-app
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

The main objective of this project is to develop a recipe browsing application using Flutter and Dart. This project helps improve mobile app development skills, UI design, image handling, and application development practices.
